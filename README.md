FlowerAura Customer Review Sentiment Analysis

## Project Overview
This project focuses on collecting and analyzing customer reviews from FlowerAura. Web scraping techniques were used to gather review data, which was then cleaned, preprocessed, and analyzed using sentiment analysis.

## Features
- Web Scraping using Requests and BeautifulSoup
- Data Cleaning and Preprocessing
- Sentiment Analysis using TextBlob
- Rating and Sentiment Correlation Analysis
- Word Cloud Generation
- Review Length Analysis
- Data Visualization using Matplotlib and Seaborn

## Technologies Used
- Python
- Pandas
- BeautifulSoup
- Requests
- TextBlob
- NLTK
- Matplotlib
- Seaborn
- WordCloud

## Dataset
The dataset contains customer names, ratings, and review texts collected from FlowerAura product review pages.

## Results
The analysis showed that the majority of customer reviews were positive, indicating overall customer satisfaction with the product.
